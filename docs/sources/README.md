Quran text, English word glosses, transliteration, Hilali–Khan translation and morphology inputs are supplied through Quranic Universal Library (QUL), Tarteel AI. Quranic Arabic Corpus morphology retains its source notices in generated content. Quran.com exports supply source word positions for validated compiled recording paths on audio.qurancdn.com; raw `audio_url` numbering was corrected where nonspoken marks caused drift; full-ayah recordings use the selected EveryAyah reciter. Retained QuranWBW notes concern their original examples. See the registry for resource identifiers, retrieval details and individual permission evidence.

The owner approved the current 300 vocabulary entries, 99 Names and formerly pending inputs for Harf release on 28 October. Seven source records are `verified` and seven `owner-approved`. The original Harf Names collection's external publisher remains unrecorded; independent editorial certification is not claimed. Similarity, themes and generated course selections remain study aids, not scholarly interpretation. Moving credits does not change those review statuses or source permissions.

The four contextual language examples are authored teaching notes tied to pinned Corpus word analyses; personal reflections and assessments belong to the learner. Prayer times use local `adhan` calculations and Open-Meteo city lookup. No Aladhan prayer-time API or new QUL recitation download is required by the current implementation.

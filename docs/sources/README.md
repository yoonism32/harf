- [Content provenance and editorial review](../CONTENT_SOURCES.md)

Quran text, English word glosses, transliteration, Hilali–Khan translation and morphology inputs are supplied through Quranic Universal Library (QUL), Tarteel AI. Quranic Arabic Corpus morphology retains its source notices in generated content. Quran.com exports supply recorded word paths on audio.qurancdn.com; full-ayah recordings use the selected EveryAyah reciter. Retained QuranWBW notes concern their original examples. See the registry for resource identifiers, retrieval details and individual permission evidence.

The original owner-selected Harf Names dataset is not independently editorially certified. Similarity, themes and generated course selections remain study aids, not scholarly interpretation. Moving credits does not change those review statuses or source permissions.
